# 🔐 Simulação de Ransomware com Python

## 📌 Sobre o projeto

Este projeto tem como objetivo estudar o funcionamento de um **ransomware**, utilizando a linguagem Python para demonstrar conceitos de criptografia e descriptografia de arquivos em um ambiente controlado.

A proposta é compreender como ameaças desse tipo operam, quais são seus impactos na segurança da informação e quais medidas podem ser utilizadas para prevenção, detecção e recuperação de dados.

O projeto possui finalidade exclusivamente **educacional e experimental**, voltada ao aprendizado de Cibersegurança e análise de ameaças.

## ⚙️ Funcionamento da simulação

O laboratório será organizado em quatro etapas:

1. **Preparação:** criação de arquivos fictícios para testes.
2. **Criptografia:** estudo da transformação de dados em conteúdo criptografado.
3. **Descriptografia:** demonstração da recuperação dos arquivos utilizando uma chave autorizada.
4. **Validação:** comparação dos arquivos originais e recuperados para verificar a integridade dos dados.

A simulação ficará restrita a arquivos de teste, sem propagação, persistência ou alteração de dados reais.

## 🛡️ Segurança e boas práticas

O projeto será executado em uma máquina virtual isolada, utilizando exclusivamente arquivos criados para fins educacionais.

Não serão realizadas operações em sistemas de terceiros, diretórios pessoais ou ambientes de produção.
